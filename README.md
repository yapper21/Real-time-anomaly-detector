# Real-Time Network Anomaly Detector

A Python-based real-time network anomaly detection system using Scapy.

## Features
- Live packet sniffing on MacBook
- Rule-based detection (Flooding, Port Scanning)
- Real-time alerts
- Works on Wi-Fi (en0)

## How to Run
1. `source venv/bin/activate`
2. `sudo python CCN_Project.py`
